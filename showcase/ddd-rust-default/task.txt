Create a Cargo workspace for meeting-room reservations with three crates: a domain crate `reservation-domain` under `packages/command/reservation-domain`, a use-case crate `reservation-use-case` under `packages/command/reservation-use-case`, and an interface-adapter crate `reservation-interface-adapter` under `packages/command/reservation-interface-adapter`. The domain models one reservation aggregate: a member reserves a room for a time slot, and the slot must end after it starts; a confirmed reservation can be cancelled once, and cancelling a cancelled reservation fails. The use-case crate declares the port for storing and loading reservations, and a use case that cancels a reservation by its ID and fails when no reservation has that ID. The interface-adapter crate implements the port in memory. Write unit tests for the aggregate, and tests for the use case running against the in-memory implementation; they must pass with `cargo test` run from the repository root.
